# Benchmark: Power BI Desktop with and without NXPilot

**English** · [Português](#português)

How many tokens does Claude Code spend to build a **complete Power BI Desktop report** (PBIP) from a dataflow —
tables, measures, relationships and pages with slicers, cards, charts and tables — **without** and **with** NXPilot?
This folder has everything needed to reproduce the test, and to build the same report **without any AI**.

Latest result: [results/RESULTS.md](results/RESULTS.md) · slide: [results/slide-en.svg](results/slide-en.svg)

## The report

[`relatorio_varejo.json`](relatorio_varejo.json) holds the rules of the report: 8 DAX measures, 4 relationships and
2 pages with 21 visuals (slicers, cards, column/bar/line/combo/donut/pie charts, tables). The data is fictitious retail
data generated by the script with a fixed seed (`dados/`: sales, products, customers, stores, targets — 5 entities,
78 columns). No real company data.

## Build it without AI

```powershell
python benchmarks\powerbi-tokens\gerar_relatorio.py             # output in .work/sem-ia/
python benchmarks\powerbi-tokens\gerar_relatorio.py --via app   # NXPilot open, script API on
```

[`gerar_relatorio.py`](gerar_relatorio.py) calls NXPilot's tools directly through its API (MCP over stdio):
`powerbi_from_dataflow` (project from the dataflow, tables reading the CSV files) → `powerbi_build_report`
(the JSON above) → `powerbi_validate`. Open `Varejo.pbip` in Power BI Desktop: the report opens with data. Same
input, same result, every time.

## The benchmark

- **Same request, twice.** The prompt is the report above in plain words (`prompt_for` in [`benchmark.py`](benchmark.py)).
- **Without NXPilot:** Claude Code writes the project and the report by itself (TMDL, report JSON, scripts).
- **With NXPilot:** Claude Code also gets NXPilot's Power BI tools over MCP, served by `NXPilot.Bench --mcp-bench`
  (the same code as the app; gate fail-closed: only LOW risk passes by itself) — or `--via app`, NXPilot open with the
  **script API** (Settings → MCP NXPilot → "Expose API for scripts", off by default).
- **Same conditions:** same model, same data, no other MCP server from the user (`--strict-mcp-config`), same allowed
  tools; both runs are told where Power BI Desktop's base theme is.
- **Measured by Claude Code itself:** `--output-format json` → `usage` (input, output, cache creation and cache read
  tokens) and `total_cost_usd` (Claude Code's estimate).
- **Checked:** `NXPilot.Bench --pbip-check` — valid project (same check as `powerbi_validate`) and **complete**: every
  measure, relationship, page and visual the report asks for.

```powershell
python benchmarks\powerbi-tokens\benchmark.py --runs 3          # average of 3 runs each, model sonnet
python benchmarks\powerbi-tokens\benchmark.py --report-only     # rebuild report and slides
```

Requirements: Windows, Python 3.10+, Claude Code signed in, NXPilot built (`build-nxpilot.ps1`), Power BI Desktop.
It spends tokens from your Claude account (the estimate is printed at the end). Scripts the agent wrote go to
`results/scripts-agente/` (local only): when the agent skips an NXPilot tool, they show what the MCP is missing.

## Português

Quantos tokens o Claude Code gasta para montar um **relatório Power BI Desktop completo** (PBIP) a partir de um fluxo
de dados — tabelas, medidas, relacionamentos e páginas com segmentações, cartões, gráficos e tabelas — **sem** e **com**
o NXPilot? Esta pasta tem tudo para reproduzir o teste e para gerar o mesmo relatório **sem nenhuma IA**.

Último resultado: [results/RESULTS.md](results/RESULTS.md) · slide: [results/slide-pt.svg](results/slide-pt.svg)

- **O relatório:** [`relatorio_varejo.json`](relatorio_varejo.json) — 8 medidas DAX, 4 relacionamentos, 2 páginas com 21
  visuais. Dados **fictícios**, gerados pelo script com semente fixa (`dados/`).
- **Sem IA:** `python gerar_relatorio.py` chama as ferramentas do NXPilot pela API (`powerbi_from_dataflow` →
  `powerbi_build_report` → `powerbi_validate`). Abra o `Varejo.pbip` no Power BI Desktop: abre com dados. Mesma
  entrada, mesmo resultado, sempre.
- **O teste:** o mesmo pedido (o relatório acima, em texto) vai ao Claude Code **sem** e **com** as ferramentas do NXPilot
  (MCP pelo `NXPilot.Bench --mcp-bench`, ou `--via app` com a **API para scripts** do Configurar, desligada por padrão).
  Mesmo modelo, mesmos dados, nenhum outro MCP do usuário. Tokens e custo estimado vêm do próprio Claude Code; cada
  projeto é conferido (válido e **completo**: todas as medidas, relacionamentos, páginas e visuais pedidos).
- Os scripts que o agente escrever ficam em `results/scripts-agente/` (só na máquina): se ele pulou uma ferramenta do
  NXPilot, mostram o que falta no MCP Power BI.
